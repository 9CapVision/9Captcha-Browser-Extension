# 9Captcha Browser Extension

This is the official Chrome extension for 9Captcha. It automatically detects and solves hCaptcha challenges in the background using your 9Captcha API key.

## Installation

1. Download this repository or the release ZIP and extract it to a folder.
2. Open Chrome and go to `chrome://extensions/`.
3. Turn on **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the folder you just extracted.

## Usage

1. Pin the extension to your browser toolbar.
2. Click the extension icon.
3. Paste your 9Captcha API key (it should look like `9cap-xxx...`).
4. Click **Activate**.

Once activated, the extension will run silently in the background. Whenever you visit a page with a supported captcha, it will automatically intercept and solve it.
